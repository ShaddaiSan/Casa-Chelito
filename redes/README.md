# Redes sociales — Casa Chelito × FORJADO

Imágenes listas para publicar en Instagram y Facebook, según la estrategia de FORJADO.
Estilo: la foto limpia a pantalla completa con etiquetas pequeñas encima; español primero y francés como nota.

- Feed: 1080 × 1350 (4:5). Historias: 1080 × 1920 (9:16).
- Se generan con `python3 tools/redes.py` a partir de las fotos de `src/images/`,
  las fuentes de `src/fonts/` y los colores del logo. Para cambiar un texto, se edita
  `tools/redes.py` y se vuelve a generar.
