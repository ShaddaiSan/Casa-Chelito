# Casa Chelito

Sitio web de **Casa Chelito**, tiendita mexicana en Montreal: pan artesanal, paletas artesanales, abarrotes, bebidas y antojitos.

Disponible en español, inglés y francés (botones ES / EN / FR).

## Páginas
- `index.html`: inicio
- `pan.html`: pan artesanal
- `paletas.html`: paletas artesanales
- `abarrotes.html`: abarrotes, bebidas y antojitos
- `contacto.html`: contacto, horario y pedidos a domicilio (solo por llamada)

## Dónde cambiar cosas
- **Teléfono, dirección, mapa y redes:** `js/config.js`
- **Textos y traducciones:** `js/i18n.js`
- **Colores y estilos:** `css/styles.css` (los colores vienen del logo)
- **Menú y pie de página:** `js/main.js`

Es un sitio estático: se puede publicar gratis con GitHub Pages (Settings → Pages → rama `main`).
