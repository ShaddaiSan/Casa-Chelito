# Casa Chelito

Sitio web de **Casa Chelito**, tiendita mexicana en Montreal: pan artesanal, paletas artesanales, abarrotes, bebidas y antojitos.

Disponible en español, inglés y francés (botones ES / EN / FR).

## Páginas
- `docs/index.html`: inicio
- `docs/pan.html`: pan artesanal
- `docs/paletas.html`: paletas artesanales
- `docs/abarrotes.html`: abarrotes, bebidas y antojitos
- `docs/contacto.html`: contacto, horario y pedidos a domicilio (solo por llamada)

## Dónde cambiar cosas
- **Teléfono, dirección, mapa y redes:** `docs/js/config.js`
- **Textos y traducciones:** `docs/js/i18n.js`
- **Colores y estilos:** `docs/css/styles.css` (los colores vienen del logo)
- **Menú y pie de página:** `docs/js/main.js`

Es un sitio estático: se puede publicar gratis con GitHub Pages (Settings → Pages → rama `main`, carpeta `/docs`).
